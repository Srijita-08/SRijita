Personal academic site for Srijita Saha, B.Sc. (Hons.) with Research in Forensic Science student at Lovely Professional University, Punjab.

Live site: `https://YOUR-USERNAME.github.io`

## Files

- `index.html`: all page content (about, education, research interests, projects, skills, contact)
- `style.css`: all styling, including dark mode
- `README.md`: this file

## Publish on GitHub Pages

- Create a public repo named `YOUR-USERNAME.github.io`
- Upload `index.html`, `style.css` and `README.md` to the root of the repo
- Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save
- Wait a minute or two, then open `https://YOUR-USERNAME.github.io`

## Edit the site

- **Text:** open `index.html` and change the words inside each `<section>`
- **Add a project:** copy one `<div class="card">...</div>` in the `#work` section and edit it
- **Add a skill:** copy one `<li>...</li>` in the `#skills` section
- **Colors and fonts:** change the variables at the top of `style.css` (`--paper`, `--ink`, `--teal`, `--tag`)
- **Pending item:** add the research paper title to the "Ongoing research paper" card
